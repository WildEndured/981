# Анализ персонажа — Этапы 1–3

Веб-инструмент для полуавтоматического разбора референса персонажа.
Работает полностью в браузере, без сервера и без зависимостей.

## Что делает

Три этапа пайплайна:

1. **Загрузка и подготовка изображения**
   - выбор картинки с устройства
   - отрисовка на `<canvas>`
   - расчёт яркости каждого пикселя (`0.299R + 0.587G + 0.114B`)
   - построение гистограммы яркостей (256 корзин)
   - автоматический подбор порога фона по самому яркому «горбу» гистограммы

2. **Маска фона**
   - BFS-заливка от краёв изображения или от точек-источников
   - два режима: по яркости или по цвету (RGB-допуск к образцам)
   - заполнение «дырок» (области фона внутри персонажа)
   - удаление «окон» (области персонажа внутри фона)
   - сглаживание границы маски (морфологическое)

3. **Точки-источники**
   - ручная расстановка точек на фоне для запуска BFS от них
   - выбор, удаление, подсветка выбранной точки
   - альтернатива — образцы цвета фона (пипетка): клик по фону → RGB в список
