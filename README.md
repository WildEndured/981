# 🖼 Mask Cutter

Инструмент для автоматического и полуавтоматического выделения фона на изображениях. Работает полностью в браузере, без сервера, без сборки, без зависимостей.

**Демо:** `https://<username>.github.io/<repo>/`

---

## Возможности

- **Три режима поиска фона:**
  - **Яркость** — по порогу яркости (быстро, для однотонных фонов).
  - **Цвет** — по образцам цвета (клик по фону задаёт эталон).
  - **Регион** — региональный рост от точек, устойчив к градиентам и теням.
- **Авто-порог** по методу Оцу.
- **Авто-поиск изолированных областей** — находит «дырки» фона внутри персонажа.
- **Морфология:** открытие (убрать острова) и закрытие (заделать дырки).
- **Сглаживание** маски (до 4 итераций).
- **Ручные точки-источники** — если автоматика не справилась.
- **Zoom / Pan** — колесо мыши, СКМ/ПКМ-drag, тач-жесты.
- **Экспорт:** маска PNG и вырезанный персонаж с прозрачным фоном.
- **Web Worker** — тяжёлые вычисления не блокируют интерфейс.

---

## Быстрый старт

1. Скачайте два файла: `index.html` и `worker.js`.
2. Положите их в одну папку.
3. Откройте `index.html` в браузере.

> **Важно:** из-за `Worker` открытие через `file://` может не работать в Chrome. Используйте локальный сервер: `python -m http.server` или `npx serve`.
